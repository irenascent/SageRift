# SageRift

SageRift is a distributed, cloud-based platform that harnesses real-time data processing and auto-scaling for streamlined enterprise analytics.

SageRift is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/SageRift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SageRift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
